ホルンれんしゅう v0.5.1（GitHub Pages公開用・試験版）
作成日: 2026-11-18

【何をするアプリか】
紙の楽譜をスマホなどで撮影・選択すると、読譜エンジンが音符・休符・音の長さをMusicXMLに変換し、
実際のホルンに近いサンプル音源で演奏することを目指したアプリです。
子ども向けの操作は「がくふを えらぶ・とる」→「ホルンで きく」が基本です。
すべての読譜結果で、原譜と音符・休符・長さを保護者が確認するまで再生できない仕組みです。

【GitHub公開方法】
1. ZIPを解凍し、index.html / app.js / sw.js / horn フォルダ等、中身を全てアップロードしてください。
2. 新しい専用のGitHubリポジトリを作ってください。既存の社内アプリと混ぜないでください。
3. GitHubの Add file → Upload files → Commit changes でアップロードします。
4. Settings → Pages → Build and deployment → Source は「Deploy from a branch」を選択。
   Branch: main / Folder: / (root) を選んで保存します。
5. 公開された https://（アカウント名）.github.io/（リポジトリ名）/ をChrome/Edge等で開きます。
6. 最初の起動はサービスワーカー有効化のため1回だけ自動で再読込することがあります。
7. 最初の楽譜読取時は読譜エンジンとモデルをオンライン取得します（約150MB＋実行用ライブラリ）。

【従来のGitHub公開手順との違い】
・独自GitHub Actionsは不要です。アップロードだけで公開できます。
・一方で認識エンジンそのもののプログラムと150MB程度のモデルはZIPに含まれません。
・ブラウザのサービスワーカー（sw.js）が、公開されているSheetscanの配布物を
  初回動作時に取得して同一サイトの実行環境へ橋渡しします。
・この方式は上流サイトの配布先/構造の変更に影響を受けるため、長期安定稼働は未保証です。
・写真自体を上流サイトへ送信する処理は、このアプリには含まれません。

【注意点と確認の限界】
・音符の認識精度は100%ではありません。認識結果が不正確だと再生も不正確になります。
・元の「Jupiter」の524×620px画像は非常に小さく、特に付点・三連符・臨時記号等に誤読の恐れがあります。
・テンポ変更、連符、休符、タイはMusicXMLに書かれた拍数・音価情報から演奏します。
・強弱、アーティキュレーション、スラーの表情、複雑な反復は再現できません。
・複数パートでは先頭のパートを演奏します。ホルンソロ向けです。
・F管ホルンでは原則として楽譜より完全5度低い音を鳴らします。
  すでに実音表記の楽譜は「れんしゅう せってい」から移調なしにしてください。
・すべての楽譜で、原譜と認識結果を大人が見比べるまで再生を許可しません。
・音程の誤認識は拍数の整合だけでは見抜けません。アプリの警告がない場合も確認が必要です。
・冒頭にテンポの指定がない場合は仮に♩=120で再生し、後から出るテンポを冒頭へ遡及適用しません。
・v0.5.1の修正：途中で初めて現れるテンポを曲の冒頭へ適用する不具合を修正、
  すべての認識結果で原譜との照合を必須に変更、指定小節開始時の跨ぎタイの再生を補正。
・v0.5.1の回帰テスト：テンポ125→145、冒頭不明→途中145、音程だけ誤った
  テスト譜での再生ロック、添付ジュピター画像の入力・警告表示、保護者確認後の
  F管移調再生のスケジュール、修正後の再確認ロック。テスト時のAI認識出力は模擬しています。
・技術検証済み：HTML/JS構文、MusicXML処理の休符・テンポ・タイ・小節位置、
  フレンチホルンサンプルの再生およびF管移調、PC/スマホの画面テスト、
  サービスワーカーのプロキシ処理（外部接続を模擬したテスト）。
・未検証：実際のGitHub Pages公開、実際のSheetscanモデルによる写真の採譜、
  添付ジュピター全曲の正確性、iPhone/Android実機、外部配布先との接続。
  現段階は【試験版】です。正確なお手本演奏を保証する完成版ではありません。

【開発メモ】
・画像上の黒点を恣意的に音符だと推測して演奏する処理は含みません。
・認識後のMusicXMLを解析して再生します。
・公開環境で外部資産の取得が失敗した場合は、読み取りに失敗した旨を表示します。
・sw.jsはGitHub Pagesの固定配布URLを動的に利用する橋渡しです。公式Sheetscanの
  本体を同梱したものではなく、将来の変更により動かなくなる可能性があります。
