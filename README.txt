ホルンれんしゅう v0.6.3（GitHub Pages公開用・試験版）
作成日: 2026-11-19

【今回の重要修正】
・1枚の写真は、実機で成功したv0.5.2と同じ単一ファイル読譜経路へ直接渡します。
・1枚のときは複数ページ用のPDF変換、事前解像度チェック、ページ一覧サムネイル生成を行いません。
・v0.6.2で同じ写真を複数回デコードしていたため、スマホのメモリ使用量が増える構造を解消しました。
・複数写真のときだけ、端末内で1つの複数ページPDFにまとめてSheetscanへ1回渡します。

【1枚の楽譜】
1. 「がくふを 追加・とる」から写真を1枚選びます。
2. その写真をそのまま読譜エンジンへ渡します。
3. 認識後、原譜と結果を見比べてからホルン音で再生します。

【複数ページ】
1. 写真を複数選択するか、後から追加します。
2. 2枚以上になった時だけページ一覧を表示します。
3. ↑↓で順番を変更、×で削除できます。
4. 「この順で 全部よむ」を押すと、写真を端末内で複数ページPDFにまとめます。
5. そのPDFをSheetscanへ1回だけ渡して読み取ります。
6. PDFは単独ファイルとして選択してください。写真とPDFの混在はできません。
7. 最大12枚までです。

【GitHub更新方法】
1. ZIPを解凍し、中身を既存のHORUNNリポジトリへ上書きアップロードします。
2. Commit message例: v0.6.3 単枚読譜安定化
3. Settings → Pages は main / (root) のままで構いません。
4. 公開後、画面右上が v0.6.3 になったことを確認してください。

【読譜について】
・Sheetscan / homr を利用します。初回は認識モデル等の取得が必要です（約150MB＋実行用ライブラリ）。
・楽譜画像の認識精度は100%ではありません。必ず原譜と比較してください。
・強弱、アーティキュレーション、スラー表現、複雑な反復は完全再現できません。
・F管ホルンでは原則として記譜音より完全5度低い実音で再生します。
